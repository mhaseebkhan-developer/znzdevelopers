# ZNZ Signature Edition V3

Upload all files in this folder together (including styles/znz-signature-v3.css and scripts/znz-signature-v3.js). Open index.html. For a previously deployed site, use a hard refresh after replacing files.

## Changes
Architectural navy, warm ivory and champagne theme; typography, navigation, hero, editorial sections, project gallery, blog, contact and footer redesigned. The original project cube remains replaced by a responsive four-card project showcase. Every project title and status has its own solid white caption; detail text has an opaque navy background. All original heading and paragraph text checked against the original, and all V2 visible strings, media URLs and links preserved. No new project claims. Original logos unchanged.

## Tests
Chromium offline rendering of all five pages at 1440, 768, 390 and 320 CSS pixels: 20 passed, with no horizontal overflow or local JS errors. All four project selections, titles, status, detail visibility and close buttons verified at every size. Mobile navigation, slider, About expansion and form validation checked. JavaScript-disabled project labels and initial detail text verified at 390px. The harness inlined local resources because direct navigation is restricted. External media, Google Translate, Maps and email handoff were not verified. Online photos appear as gradients in offline previews.

## Existing limitations
Contact form opens the visitor’s mail application; no server submission backend was supplied. Blog Read More links remain original placeholders. Online-media provenance and licensing notes remain in ONLINE_MEDIA_NOTES.md.
